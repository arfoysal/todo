# 📝 Local-First To-Do Workspace

A beautiful, advanced task management application built entirely in a single HTML file. It runs instantly in your browser, requires zero setup, and keeps 100% of your data private.

## ✨ Features

* **Zero-Setup & Serverless:** No backend, no databases, and no login required. 
* **100% Private:** Uses your browser's Local Storage. Your tasks never leave your device.
* **Modern UI/UX:** Premium glassmorphism design with smooth animations and a responsive layout.
* **Dark Mode:** Built-in toggle to seamlessly switch between light and dark themes.
* **Advanced Task Management:**
  * Create tasks with custom colors, labels, and due dates.
  * Break down large goals into trackable subtasks.
  * Drag-and-drop to reorder tasks or convert them into subtasks.
  * Powerful search and filtering.
* **Data Portability:** Export your entire workspace as a JSON file and import it on any other device or browser.

## 🚀 How to Use

### Option 1: Use it instantly (GitHub Pages)
*live link here: [Live Demo](https://arfoysal.github.io/todo/)

### Option 2: Run it locally
Since the entire application is contained within `index.html`, you can simply download the file and double-click it to open it in any modern web browser. No local server required!

## 🔒 Privacy

Because this app utilizes Local Storage, **your data is completely private**. Even if this repository is public and hosted on the web, any data you enter is stored only on the specific device and browser you are using. No one else can see your tasks.
